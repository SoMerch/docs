Live

Available for teams to use today:

  • Zapier app - approved and listed on the Zapier Marketplace
  • ChatGPT connector - live through the SoMerch public MCP server
  • Public MCP server - for AI agents and MCP-compatible clients
  • Public REST API - OAuth, webhooks, events, and OpenAPI reference

In review

Built, submitted, and currently in the review phase with the respective platforms:

  • ChatGPT plugin directory listing (in review by OpenAI)
  • Microsoft Copilot - AI assistant built on the SoMerch public MCP server
  • Canva app - find products, prepare artwork with your logo, and send a quote
  • monday.com app - create shipments and track shipment status from workflows
  • Google Sheets app - Google Workspace Marketplace listing

In development

  • Salesforce - connecting merch operations with Salesforce
  • Deel - connecting merch operations with Deel
  • HubSpot - connecting merch operations with HubSpot
  • HiBob - connecting merch operations with HiBob

What the status means

Live means the integration works today. In review means the integration is built and submitted for approval to the platform's marketplace or directory. In development means the integration is actively being worked on.
