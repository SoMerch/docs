Integrations

SoMerch connects corporate merch operations with the tools teams already use. Working connectors, ecosystem milestones, and upcoming integrations are all listed here.

Integration ecosystem. SoMerch ships official integrations for AI assistants, no-code automation, design tools, and business platforms. Each connector's current status is listed below.

Live

Available for teams to use today:

  • Zapier app - approved and listed on the Zapier Marketplace
  • ChatGPT connector - live through the SoMerch public MCP server
  • Public MCP server - for AI agents and MCP-compatible clients
  • Public REST API - OAuth, webhooks, events, and OpenAPI reference

In review

Built, submitted, and currently in the review phase with the respective platforms:

  • ChatGPT plugin directory listing (in review by OpenAI)
  • Microsoft Copilot - plan company merch, search products, build project recommendations, and request quotes through a Copilot agent on the SoMerch public MCP server
  • Canva app - find products while designing, prepare branded artwork, preview the result, and send the selected merchandise for a quote
  • monday.com app - turn people and order data from boards into SoMerch shipments by mapping recipients, products, sizes, and quantities
  • Google Sheets app - manage products, recipients, and assignments, then import the resulting individual shipments into SoMerch

In development

  • Salesforce - connect records and workflows so merch requests and fulfillment become part of CRM processes
  • Deel - connect employee data to support onboarding, gifting, and distributed fulfillment workflows
  • HubSpot - connect contacts and workflows so data can trigger and support merch requests and fulfillment
  • HiBob - connect employee data so HR events can trigger merch and gifting workflows

What the status means

Live means the integration works today. In review means the integration is built and submitted for approval to the platform's marketplace or directory. In development means the integration is actively being worked on.
